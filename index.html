Before the first session

Three things, about ten minutes, so you can start working the moment class begins.

  1. Sign in to Microsoft Copilot. Go to copilot.microsoft.com with a free Microsoft account. If you already use ChatGPT, Gemini, or Claude, you may use it for every exercise instead.
  2. Sign in to Microsoft Learn. Open learn.microsoft.com with the same account. You will use it in the last lesson to earn your trophy.
  3. Download the workbook and the prompt library template. Both are in Downloads below. Bring a laptop if the session is not in a computer lab, and bring one real task you would like help with.

The one formula you will use all day

Every good prompt answers up to four questions. You only need the first one to start.

GoalWhat should the AI do?
ContextWhy, and for whom?
SourceWhat should it use?
ExpectationsHow should the answer look?

Google teaches the same idea as Persona, Task, Context, Format. You will see both in class.
